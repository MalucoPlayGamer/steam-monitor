# steam-monitor

Automatically published Steam client data. Do not edit by hand.

The data lives on separate orphan branches — this branch (main) only carries documentation.

| Branch | Contents |
| --- | --- |
| [pattern](../../tree/pattern) | Steam client rule patterns (TOML files named by SHA-256 hash) |
| [ipc](../../tree/ipc) | Steam client IPC interfaces & VTable RVAs |
| [protobuf](../../tree/protobuf) | Steam client protobuf definitions |

Each branch contains metadata files updated automatically whenever Valve publishes a Steam client update.
